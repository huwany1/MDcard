# 大きなアイデアのための、小さな空間。

**MDcard** へようこそ。静かに書き、考え、誰かに届けたいものを作りましょう。

> 大きなことは、短い言葉から始まります。

## 自分らしく書く

- **Markdown** で書くと、すぐに結果を確認できます。
- 編集・分割表示・閲覧を切り替えられます。
  - 文章はあなたのもの。プレーンな UTF-8 ファイルに保存します。
  - Windows と Linux に対応しています。

## 小さな計画

- [x] 静かな場所を見つける
- [x] アイデアから始める
- [ ] すてきなものを作る

## すべてを整える

| 機能 | 説明 |
| :--- | :--- |
| ライブプレビュー | 見出し、リスト、引用、表 |
| ローカルファイル | アカウント不要で開く・編集・保存。 |
| 多言語対応 | 日本語・中国語・韓国語フォントを内蔵。英語・ロシア語にも対応。 |
