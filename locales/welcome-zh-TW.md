# 為大想法留一方小天地。

歡迎來到 **MDcard**，安靜書寫、思考，創作值得分享的內容。

> 好的想法，值得被認真記錄。

## 隨心書寫

- 使用 **Markdown** 書寫，即時查看效果。
- 在編輯、分割和閱讀之間切換。
  - 你的文字由你掌握：純 UTF-8 檔案。
  - 支援 Windows 和 Linux。

## 一個小計畫

- [x] 找個安靜的地方
- [x] 從一個想法開始
- [ ] 創造精彩內容

## 井然有序

| 功能 | 說明 |
| :--- | :--- |
| 即時預覽 | 標題、清單、引言和表格 |
| 本機檔案 | 開啟、編輯、儲存，無需帳號。 |
| 多語言支援 | 內建中日韓字型，也支援英文與俄語。 |
