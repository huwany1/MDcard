# Немного места для больших идей.

Добро пожаловать в **MDcard** — спокойное место, чтобы писать, думать и создавать то, чем хочется поделиться.

> Большие дела начинаются с нескольких слов.

## Сделайте по-своему

- Пишите в **Markdown** и сразу видите результат.
- Переключайтесь между редактором, двумя панелями и чтением.
  - Ваш текст остаётся вашим: обычные файлы UTF-8.
  - Работает в Windows и Linux.

## Небольшой план

- [x] Найти тихое место
- [x] Начать с идеи
- [ ] Создать что-нибудь прекрасное

## Всё на своих местах

| Возможность | Описание |
| :--- | :--- |
| Предпросмотр | Заголовки, списки, цитаты и таблицы |
| Локальные файлы | Открывайте, редактируйте, сохраняйте без учётной записи. |
| Поддержка языков | Встроенные шрифты для китайского, японского и корейского. Поддерживаются английский и русский. |

## Создано на Rust

```rust
fn main() {
    println!("Привет, мир!");
}
```
