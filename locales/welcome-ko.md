# 큰 생각을 위한 작은 공간.

**MDcard**에 오신 것을 환영합니다. 차분하게 글을 쓰고 생각하며 나누고 싶은 것을 만들어 보세요.

> 위대한 일은 몇 마디 글에서 시작됩니다.

## 나만의 공간

- **Markdown**으로 쓰고 바로 결과를 확인하세요.
- 편집, 분할 보기, 읽기 모드를 전환하세요.
  - 글은 온전히 내 것입니다. 일반 UTF-8 파일로 저장됩니다.
  - Windows와 Linux에서 사용할 수 있습니다.

## 작은 계획

- [x] 조용한 곳 찾기
- [x] 아이디어로 시작하기
- [ ] 멋진 것 만들기

## 제자리에 정리하기

| 기능 | 설명 |
| :--- | :--- |
| 실시간 미리 보기 | 제목, 목록, 인용문, 표 |
| 로컬 파일 | 계정 없이 열고 편집하고 저장하세요. |
| 언어 지원 | 한국어, 중국어, 일본어 글꼴 내장. 영어와 러시아어도 지원합니다. |
