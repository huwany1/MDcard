# 为大想法留一方小天地。

欢迎来到 **MDcard**，安静书写、思考，创作值得分享的内容。

> 好的想法，值得被认真记录。

## 随心书写

- 使用 **Markdown** 书写，即时查看效果。
- 在编辑、分屏和阅读之间切换。
  - 你的文字由你掌握：纯 UTF-8 文件。
  - 支持 Windows 和 Linux。

## 一个小计划

- [x] 找个安静的地方
- [x] 从一个想法开始
- [ ] 创造精彩内容

## 井然有序

| 功能 | 说明 |
| :--- | :--- |
| 实时预览 | 标题、列表、引用和表格 |
| 本地文件 | 打开、编辑、保存，无需账户。 |
| 多语言支持 | 内置中日韩字体，也支持英文与俄语。 |
