## 设计

一张竖向圆角卡片中，以真实透明负空间切出一个几何 M。卡片对应文档与 MDcard 名称中的 card，M 对应 Markdown。符号仅保留卡片与 M；没有折角、铅笔、书本、代码符号、正文横线或文字标签。M 的圆头、圆转角与卡片圆角保持柔和一致，适配现有简洁原生界面。

主版本仅使用一种实色 **MDcard Blue `#2D5BCA`**，取自当前编辑器的浅色默认蓝色强调值。黑色版为 `#000000`，白色版为 `#FFFFFF`。三个版本的几何和 Alpha 完全相同，没有独立背景板、阴影、渐变、纹理或玻璃效果。M 与卡片外部都是真透明；预览里 M 显示的颜色来自它后面的背景，不是绘制的白色或黑色。

建议：浅色界面用彩色或黑色版，深色界面用彩色或白色版。黑、白单色版按背景选择，不能把纯黑放在纯黑底上要求可见。复杂背景见原尺寸预览；若部署位置恰好与蓝色相同，可选对比明显的单色版。本交付不声称图标能在任意同色背景上自动维持对比。

## 网格、比例与安全留白

大尺寸源文件采用 **64×64** 网格，三个主 SVG 具有相同 viewBox：

| 元素 | 参数 |
| --- | --- |
| 外卡片 | x=8、y=4、宽=48、高=56；宽高比 6:7 |
| 卡片圆角 | r=12，与卡片宽度的 1/4 相同 |
| 画布安全留白 | 左右各 8（12.5%），上下各 4（6.25%）；无出血 |
| M 中心线 | (20,43) → (20,22) → (32,34) → (44,22) → (44,43) |
| M 笔画 | 7.5；圆端点、圆连接；两竖笔等粗 |
| M 左右轮廓 | x=16.25～47.75，完全在卡片内部 |
| 光学位置 | M 包围框中心 y=32.5，比画布中心下移 0.5，用于平衡肩部与上方斜线的视觉重量 |

SVG 的白色卡片遮罩和黑色 M 遮罩仅控制 Alpha，实际可见的填色只有主色/单色。编辑 `defs > mask` 中的 `rect` 与 `polyline` 即可调整卡片和 M；外层同尺寸 `rect` 设置可见填色。源文件不依赖字体、位图、外部链接、脚本或滤镜。

## 小尺寸光学校正

16/24/32px 使用 `svg/optical/` 中各自的可编辑原稿并直接栅格化。48px 起使用主 SVG 按目标像素栅格化；不会先渲染一个大 PNG 再缩小。

| 尺寸 | 卡片 x/y/宽/高/r | M 中心线 | 笔画宽 |
| --- | --- | --- | --- |
| 16 | 2 / 1 / 12 / 14 / 3 | (5,11) → (5,5.5) → (8,8.5) → (11,5.5) → (11,11) | 2 |
| 24 | 3 / 1.5 / 18 / 21 / 4.5 | (7.5,16.5) → (7.5,8.25) → (12,12.75) → (16.5,8.25) → (16.5,16.5) | 3 |
| 32 | 4 / 2 / 24 / 28 / 6 | (10,22) → (10,11) → (16,17) → (22,11) → (22,22) | 4 |

相对于主网格直接缩放，小尺寸 M 笔画从 1.875/2.8125/3.75px 加粗为 2/3/4px，M 两竖笔端点下移，保住清晰的竖笔和中心 V 形；16/32px 的竖笔轮廓落在整数像素边界。允许曲线边缘有正常抗锯齿，但透明外部没有有色底板或光晕。

## 查看与重建

先运行下列 preview.py，再打开本地 `preview/index.html`。用于尺寸验收时，浏览器缩放设为 100%；所有 `data-actual-size` 图像都保持图片像素=CSS 像素。物理显示像素仍取决于操作系统缩放和 DPR，未把这等同于所有屏幕的物理尺寸。

生成环境：Node.js，`@resvg/resvg-js 2.6.2`，Python 3，Pillow（`tools/requirements.txt` 记录版本）。渲染器是开发时依赖，SVG/PNG/ICO/HTML 使用时不需要安装它。

```powershell
cd assets/branding/mdcard-icon/tools
npm.cmd ci --ignore-scripts --no-audit --no-fund
python -m pip install -r requirements.txt
node generate.mjs
python preview.py
python verify.py
python package.py
```

`preview.py` 默认使用 Pillow 内置字体，可通过 --font 显式指定标签字体；字体只用于预览说明，SVG 图标和 PNG 图标本体不含文字或字体依赖。`package.py` 生成 SHA256 清单并将本目录交付文件归档到 `artifacts/icon-design/MDcard-icon-kit.zip`，不包含 `node_modules`、浏览器缓存、Git 数据或应用程序包。

## 验证边界

资源自检不替代新二进制的平台显示验收。复杂桌面背景为生成的图形模拟；预览不是程序截图。图标识别性的结论来自实际尺寸视觉审查，不等同于用户群体研究或商标检索。
