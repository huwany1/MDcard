# 阅读精确恢复实现合同（2026-10-23）

本轮按阶段 A（文字/源码行）与阶段 B（大幅修改后的重定位）分别实现、构建、真实 GUI 验收和提交。本文冻结行为与预算，不是通过记录。独立验收和原始 A-01..D-05 完整条文保留于 `READING_PRECISION_ACCEPTANCE.md`，不得以块级结果替代文字命中。

## 坐标与锚点

- 原始 Markdown 或解码后的 TXT 是唯一源码坐标系。UTF-8 byte、Unicode scalar、Unicode 扩展字素簇、源码逻辑行、当前排版视觉行分别表示；不把预览字符串偏移视为原稿偏移。
- 正常滚动时选择视口中最靠上、可可靠映射到原稿、实际可见的文字字素簇；同高度时选择最靠左的可见文字。跳过零尺寸控制符和无法映射的装饰。顶部是非文字时可选择下方仍在视口中的文字；没有可映射文字则保留明确块级锚点。
- 文字锚点记录原稿范围、字素簇范围与有限正文上下文，以及实际 glyph/galley 顶部相对视口的 y。光标、选区和阅读锚点独立，不借请求焦点或移动光标恢复阅读。
- 恢复、连续宽度/字体/模式重排、异步高度补偿保持同一已选择内容锚点；用户真实滚动或明确导航后才允许重选。不能每次重排重选新视觉行起点累积漂移。
- 同内容同布局每轴偏移误差 ≤2 logical px；重排后命中相同原文字素簇且其实际 viewport y 误差 ≤2 px。首尾、横向范围不足及锚点无法到达所需 y 的夹取分开记录原因和实际误差，不进入未夹取精度分母。
- 隐藏 Markdown 语法和图片/公式/图表等生成节点不能冒充可见字素；明确报告文字、源码逻辑行、块、章节、近似、无效等级及原因。编码实体/转义必须报告实际显示内容和原稿 token 范围。
- 诊断为只读：保存锚点与本帧实际 galley 的目标字素簇 rect 分开；可选公开可见文字/原稿范围/实际 rect，父代理独立对照原稿和截图。不提供注入位置、匹配结果或人为延迟接口。

## 纯 API 与阶段

`src/reading_precision.rs` 提供可直接引入真实源码的通用 API：

```rust
pub fn capture(text: &str, byte: usize) -> Anchor;
pub fn resolve(text: &str, anchor: &Anchor) -> Resolved;
```

Anchor/Resolved 可 serde。Resolved 明确包含 `exact`、`source_byte`、`grapheme_range`、`tier` 和 `evidence`。这里 exact 仅表示正确对应文字的证据成立，不表示视口已达到像素容差；GUI 实际几何另验。

阶段 A 只对内容未变的源锚点作文字级对应，使用真实布局反算位置；旧块记录在有真实文字观测前不自动升级文字级。阶段 B 才加入有限上下文、标题路径、邻块和可验证局部 diff，要求候选全局唯一；不能以 first、nearest、旧行号或百分比打破歧义。原锚点已删、无关文稿、证据不足均降级，不声明 exact。

独立集合由主代理事先冻结，至少 1000 可判定、200 歧义、200 删除/无对应，量化 ≥30% 字符编辑和 ≥30% 块移动。保留全部分母和失败，命中率 ≥98%，观测错误 exact=0；算法不读取 oracle、文件名或夹具特判。

## 线程、缓存与存储

- 实现前冻结主线程 capture+plan+submit：P95 ≤2 ms，单次 ≤8 ms；真实按需排版另列。整 GUI update P95 相对同机同文档同输入的实施前 `264d42d` 功能基线增量 ≤max(20%,2 ms)。后台取消可见响应 ≤100 ms。超预算优化或失败，不测后调阈值。
- 所有计时采用可核查方法，`Instant.elapsed` 是函数墙钟区间而非线程 CPU。索引、匹配、排版、主线程提交、磁盘分别报告 P50/P95/max/n，不冒充显示时延或 FPS。
- 文档索引/匹配在后台按 DocumentId+BufferId+revision+epoch 校验；切换不等待旧匹配，迟到结果丢弃。主线程不每帧全文扫描/哈希/挂载/写盘。普通、1 MiB、10 MiB、长段、大量重复分别采基线和新构建；长段中末部只按需挂载可见排版范围。
- 保留稳定 DocumentId 与非持久化 BufferId、主副窗格/视图独立状态、搜索/目录/用户滚动优先、原稿保存/撤销/同步/大文档虚拟化保护。
- 状态 schema 安全迁移，旧记录明确降级；只持久化有限片段，不存全文。512 条/4 MiB、单个/全部清除 epoch、按文档合并和系统锁/原子替换继续生效。失败保留内存和上一有效落盘记录，提供可查看提示，不改原稿。

## 交付约束

阶段 A 和 B 分别给当前源码、必要自动化、真实 Windows/Linux GUI、性能/故障记录和构建快照；主代理协调提交和独立验收。最终完整包记录源码/二进制/资源 SHA256 并包内复验。未验证平台/内容/精度和全部失败显式保留。外部移动识别、草稿正文跨重启恢复仍不属于阅读位置承诺。

## 当前实现的观测边界

`views[key].geometry` 是原稳定目标在本帧实际 Galley/TextShape 中的字素矩形，带 `origin=galley-current-pass`，不回显保存的 y。`position.text_anchor` 是持久化目标。`visible_text` 保持逐字素字段；`visible_runs` 另外公开实际可见文字段，两者仅在 `MDCARD_READING_GEOMETRY_REPORT=1` 时收集。源码逻辑行 `logical_line` 从当前 revision 缓存的原稿换行索引取得，与 `visual_row` 分开。

实体的 `source_byte/source_end/grapheme_range` 指合法原稿代表字素，`token_range` 单独指整个实体 token，`text` 指真正显示内容。虚拟窗口缺少一个原始字素的前缀或后缀时不能声明该字素已绘制；窗口边界按原稿扩展字素对齐。零宽不可见控制内容不作为文字锚点。

滚动恢复控制使用 0.75 logical px 停止带吸收物理像素量化；验收仍为未夹取样本 ≤2 px。巨长源码逻辑行在恢复完成后继续围绕同一文字目标选择虚拟窗口，用户实际滚动/明确导航才解除，避免估算行窗口与精确补偿形成反馈。

P02 的 `layout_wall_ms` 分开记录源码 `SourceLayout`、虚拟源码/TXT 的真实字体排版调用，以及 Markdown/代码块实际布局和绘制区间。后者包含该依赖的解析、控件分配、字体缓存和绘制，不称作隔离的字体 CPU；`main_commit_wall_ms` 记录实际 ScrollArea 偏移提交。所有值均为函数墙钟。读取只读诊断的 I/O 和 `/proc` RSS 采样不是显示延迟、FPS、线程 CPU 或私有分配器峰值。

现有 `rich.scrollCpuMs` 只覆盖 GUI 主段的墙钟区间：入口前置任务与末尾清理、诊断输出不在该区间内。阶段 A 该样本不作为完整 update 预算通过证据。阶段 B 将在实施前 `264d42d` 的隔离归档与最终 A+B 源码上加入相同的完整入口到返回观测，记录补丁、源码与二进制哈希，在相同诊断配置下比较。R10 与阶段 B 的配对只能说明 B 增量，不能替代实施前基线；完整 update 预算在取得该对照前标为未验证。

完整 update 对照在 B 产品接入前另冻结两组，门槛仍为 P95 增量 ≤max(实施前值的 20%,2 ms)：正常运行 `diagOFF` 为主结论，只启用相同异步入口观测，UI/reading/rich 同步诊断关闭，产品阅读状态持久化保留；`diagON` 使用原有同步诊断与异步入口观测，单列配对结果和观测模式限制，不能用任何一组隐去另一组失败。每组均在实施前 `264d42d` 仅加相同观察的隔离构建与最终 A+B 间同机、同稿、同 flags 比较。

`diagOFF` 协议为 `scripts/measure-reading-precision-entry-linux.py`：两个真实进程分别打开同档 MD/TXT，1240×820、字体15、默认 Split 用真实 Ctrl+E 切 Read；A 向下100次、B向下55次、A向上25次，间隔65 ms，每段后1秒等待；原生窗口和鼠标坐标相同。通过持久化文件与截图确认真实位置和原稿哈希不变。普通、1 MiB、10 MiB 输入含长段/重复内容，分别报告两种格式的全部 update 调用及真实 wheel 调用 P50/P95/max/n；同一 egui frame 的多次 update 之和另列。入口探针是首语句 RAII 到返回前最后局部 guard 析构，现有诊断 I/O 包含，探针自身入队及后台 JSON 不在采样区间；队列丢样必须为0。它是函数墙钟，不是 framework render、线程 CPU、显示延迟或 FPS。

异步恢复读取当前挂载图片的真实 `TexturePoll`（与实际 Image 控件相同 URI、尺寸选项和可用尺寸），而不是仅判断原文件 bytes 已就绪；可见公式单独报告当前布局等待。非文字历史恢复期间不从临时顶部采集文字锚点。恢复完成同时要求实际呈现偏移及已保存文字目标的真实几何可用，不能以连续相等的请求值或固定次数宣称完成。新的实际字素修正作为下一帧输入，避免反复重设粗块偏移。主副源码窗口均保护保存字素所在逻辑行的按需挂载。

`layout_pending/asset_errors/presented_offset/range_clamp` 是只读当前布局观测。图片失败后的可达范围夹取单列；它不宣称文字精确。可等待的异步加载期间保留旧记录，实际滚动或明确导航可立即取消。阶段 A 真实输入取消延迟仅代表该次布局恢复；阶段 B 匹配任务的取消另行实测。

无法映射或无法收敛的恢复使用有限预算：布局已就绪时最多 120 次呈现尝试或 3 秒；异步资源最多等待 30 秒。超限明确报告 `failed_restore` 的块级降级、原保存目标、实际偏移和原因，停止自动滚动及自动覆盖旧有效历史，直到真实滚动或明确导航。上方高度变化让目标 run 暂未绘制时，清除陈旧的数值 target，按当前高度索引再次挂载同一保存字素所在块，再从真实 Galley 计算；不重选 pin。

`cancel_events` 只读记录原生输入被处理时的 `had_pending/raw_wheel/frame/document_id/generation`，用于区别实际取消待恢复任务与恢复早已自行结束。阶段 A 元数据索引仍只有后台计算与 epoch 拒绝迟到结果；这不等于旧计算已经中止。真正索引/匹配取消、旧任务停止延迟及新任务不等待旧计算，在阶段 B 单独实现和验证。


## 阶段 B 的实现约定

纯 API `capture(text, byte)` / `resolve(text, anchor)` 与 GUI 使用相同源模块。GUI 按 buffer/revision 建一次 `Arc<String>` 源快照；热路径只采有限字素上下文，停止滚动后在后台补全见证，不逐帧复制或哈希全文。旧锚点保留有限上下文、标题哈希路径、最多四个唯一邻块片段及每块最多四个原稿中已验证唯一、来自不同 offset 的短字素片段、非局部原稿见证、完整节点哈希/原字节偏移；最多另保存 4 KiB 的原节点片段及有限唯一种子。单锚 proof 序列化上限 8 KiB，增强装不下时舍弃该增强，保留原有较小证据；状态总容量仍为 512 条/4 MiB。不创建随全文大小增长的版本快照；持久化仅限上述有界片段，极短文档可能被片段完整覆盖。

未变节点用完整字节身份与可验证唯一作用域定位。局部改写可由仍存活的全球唯一段内见证及紧邻节点边界约束有界差异映射；所有同样最优路径必须将原字素映到同一合法原稿字素，否则降级。候选截断不作为唯一性证据。短标题还须唯一存活邻块或结构作用域，不能仅凭一个公共短句就声明精确。没有完整外部编辑历史时也使用这些原文证据；不会按文件名、旧百分比、最近候选或者独立夹具规则认定精确。

`views[key].relocation` 独立保留最后一次版本定位的 exact/tier/reason、原锚点、候选证据、任务元数据及最终布局状态。其精度等级与本帧可见 `geometry` 分开：降级落点上的新文字可正常绘制，并不将旧锚点对应升级为精确。低等级依次选择可验证存活邻块、唯一标题路径、文档比例、空稿/无效顶部；源码逻辑行正确性仍单独观测，不与视觉行或文字 exact 合计。

索引、旧锚 enrichment、匹配和新锚 enrichment 使用真正计算检查点与原子取消 token。身份绑定 DocumentId、BufferId、revision、打开代次、恢复 epoch、clear epoch。切换、版本变化、清除或明确导航使旧任务取消；后台停止与丢弃迟到结果分别记录。`background_tasks` 只读提供实际开始/退出、取消时 phase/checkpoints、排队/计算/取消至退出墙钟区间；只有任务确在计算且真实输入取消的样本才能证明计算停止，不以 pending 消失代替。最终实测与未验证项由验收报告逐项给出。

版本定位完成后，在偏好设置“阅读位置”的“最近阅读恢复”内保留每个窗格最近一次的精度等级与简明原因；仅保存有界摘要，不向普通界面展示线程或任务标识。该摘要与有界锚点证据一起受单文件/全部清除、容量限制和多实例合并约束。

状态 schema 3 分开保存实际阅读活动时间与后台元数据更新时间，兼容旧 schema 1/2 的安全升级。只有真实打开、正文滚动、编辑或明确导航提升活动时间；后台补全、布局、焦点/悬停、摘要更新不能让另一实例已经清除的旧记录复活。每次显式切换先读取外部清除标记，再允许新打开成为活动；不会用旧内存位置先恢复再追认新时间。该检查不在逐帧滚动路径执行。默认 schema 3 使用独立 reading-state-v3.json，首次缺失时只读迁移旧 reading-state.json 的 v1/v2 数据，不修改旧文件；旧版本默认继续写旧路径，不能覆盖新字段。显式环境变量强行让旧二进制与新状态共用同一路径属于不支持的跨版本配置。新 writer 遇到已存在文件的未来版本、损坏或无效字段一律拒写，保留原 bytes、内存和可查看错误；只有文件缺失授权新建。

有界差异的内部唯一见证是强制映射约束，不仅是候选块的存在证据。段落拆分/合并后使用可验证紧邻前缀给出完整外边界，全部最优映射仍须一致；缺少完整可靠区间时降级，不能把截断块的旧尾映到相邻重复正文。

邻段片段不要求从 offset 0 开始；遇到前缀内拆分时，把原先保存的上下文尾部一起放入旧侧差异输入，并同时强制旧节点内部与邻节点片段的新旧对应。不能从新片段位置简单减旧偏移来猜块边界。所有证据保持原文坐标与实际范围，候选不一致仍降级。

相邻原节点额外只保存最多 8 字节的真实空白间隔。内部短片段不唯一时，可由两个原稿/新稿均唯一的外部片段，加完整旧节点和真实间隔构成三节点差异输入；两端均为强制对应，不要求新稿仍是单个语义块。删除、歧义或最优路径映射不一致时不授予文字精确。

持久化时间字段同时校验 clear、record.updated/activity、position.updated、恢复摘要.updated：必须可表示在 UTC 公历 9999 年内，且不超过本机当前时间 24 小时。超界文件拒绝读写并保留原 bytes，位置仍可在内存使用；时间增量采用饱和加法，不能由 u64 极值触发回绕或压过后续清除。系统时钟回拨超过容差时同样安全拒写，待修正时钟或处理状态文件。

后台替换/回滚返回的新 buffer 仅更新绑定和代次，不计作新的打开活动；该重绑同样先观察其他实例的清除。用户真实打开与后台提交使用不同活动语义，不能靠 worker 完成时间复活已清除记录。

相邻完整小节点的前缀/后缀见证须在原稿、新稿实际核验唯一、字素范围与顺序；非唯一短摘录不能获得身份。仅逐字素强制相等的连续外边界可从动态差异矩阵折叠；每个固定匹配的 4 分加回总分，hunk、门槛和源坐标仍按完整范围计算。动态旧/新矩阵预算维持 1536/4096 字素，定位索引节点含真实逻辑行，最多 50,000 个；不把超预算降级算作文字成功。

清除是独立事务：在系统锁内读取最新磁盘，用有界单调 clear_serial 建立屏障，与 future 元数据更新时间分开。只有显式清除请求可删除，普通 deleted 快照不能重演清除。清除后的真实运行期活动可重新保存，载入的未来活动时间不能授权旧快照；序号非法或耗尽拒写保留原 bytes、内存与可查看错误。未填写新字段的旧记录按安全默认值迁移，新增字段仍受 512 条/4 MiB 限制。

任务结果先入队，再发布实际完成时间并通知原生事件循环重绘；旧任务只保留其创建时的 Context，不能借完成通知重绑窗格或版本。后台计算取消、事件处理和读取诊断的采样开销分别报告。原生输入到已完成原始记录读完可形成观测上界；事后 JSON 解析耗时另列，不将 pending 消失或内部 token 函数时长替代实际退出。

单文件墓碑被容量淘汰后，全局有界 `clear_serial` 与最近一次真实清除时钟仍作为缺失 key 的屏障；旧实例只更新元数据不能复活。切换先用同一屏障废弃落后且磁盘缺失的内存历史，再承认真实打开；已存在的未清文档不受其他文档的单清影响。旧格式缺少清除时钟时可从仍存的显式清除记录推导，完全未知不能授权旧快照；新的真实打开先记住所见屏障，仍可记录新阅读。新增时钟字段沿用类型/UTC/未来范围校验与拒写保护，不扩大记录数量或总容量。

标题/状态/主副窗格的 dirty 展示和普通稿行/scalar 计数仅在真实正文 revision、保存基线或格式 key 改变后重算；实际保存/关闭/切换仍使用未缓存的全文保护判断。普通预览与目录按 BufferId/实际内容 revision 门控源比较和解析，异步 poll、debounce 与布局继续每帧处理。源码排版对普通≤64KiB正文或虚拟窗口的行/hash/字体缓存检查独立计时，不承诺第三方绘制全部O(1)；不能把界面摘要或块级位置代替正文保护与文字精度。

普通副窗格源码也使用实际 Galley 与原文线性映射，文字锚点、横纵滚动及持久选区分别处理。失焦时 TextEdit 的可见 cursor_range 为空不代表选区已归零；选区读取实际 TextEditState，不请求焦点或移动光标。

预览必须等实际用于绘制的正文版本提交后才采集当前几何或完成恢复；请求中的 revision 不等于已安装的解析版本。普通 debounce、large→ordinary 切换及大稿异步安装等待期间保留有效历史，不把旧节点映射套在新正文上。高内容块的字节比例只可估算首次挂载区域，最终精确决定必须来自目标字素的本帧实际 Galley。

内部重命名在同一锁事务中迁移新 key 和旧路径墓碑，保留稳定身份、位置及选区，不伪造阅读活动；路径改变强制提交即使首份记录仍在队列或处于同毫秒。普通单清与未触及的新记录同一事务时，缺失 key 按锁进入前的全局屏障审核；其他实例先前的清除及全清仍保持有效，不能由旧快照绕过。

新打开的大稿源码有历史位置且本次尚未挂载实际窗口时，等待该 buffer/revision 的索引后直接挂载历史区域，不先测量临时顶部并改变同布局的高度坐标。等待仍登记实际 source ID、viewport/layer 并保留非零全局选区，真实导航或滚动可取消。已有窗口的普通编辑、IME 与 worker-clone 重绑继续处理实际 TextEdit 输入，不因新 revision 索引或匹配未完成显示阻断占位。
