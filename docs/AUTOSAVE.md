# 自动保存

此功能属于本次未发布源码改动。已有 0.1.0 正式安装包没有被替换；从旧包升级前请确认所用构建包含此功能。自动保存继续只负责原文件写入；独立保护见[稿件崩溃恢复](CRASH_RECOVERY.md)。

## 开启与关闭

自动保存**默认关闭**。全新设置、旧设置缺少该字段、设置读取失败后使用默认设置时，均为关闭。已经明确保存过 `autosave: true` 或 `false` 的用户保持原选择；独立恢复保护默认开启，不要求原文件自动保存开启。

打开现有设置窗口（`Ctrl+Shift+P`），可以随时关闭或重新开启“自动保存”。

设置中的说明为：**“停止编辑 2 秒后写入原文件；未命名文档需先手动保存。”** 开关立即生效，并使用现有设置文件记住选择。下次启动恢复此前主动选择。若保存设置失败，会明确显示“自动保存的选择仅在本次会话生效，尚未记住”；本次关闭选择仍然有效，不会因设置写入失败偷偷重新开启。相同失败设置不会逐帧重试；再次调整设置时会重新尝试保存。

关闭开关会取消尚未提交的自动保存。若一次保存已经进入磁盘提交阶段，它可以完成；此期间新增的编辑仍保持未保存状态。

## 编辑与首次保存

主文档和副文档各自等待和保存。对已经具有保存路径、存在有效修改的文档，停止有效编辑 2 秒后自动保存；每次有效修改重新开始等待。开启时已经存在的修改也会进入等待。连续输入会合并保存；仅滚动、选择、搜索或切换主题不算编辑。计时器在没有鼠标或键盘输入时也会推进。

源码输入、撤销重做、当前文档替换、可编辑表格、任务列表及公式/图表的有效源码同步使用同一流程。只改变保存编码或 BOM，也属于待保存修改。原有换行字符与所选编码、BOM 规则继续由保存核心处理。

未命名文档显示“先手动保存以启用自动保存”。先按 `Ctrl+S`，自行选择首次保存位置；自动保存不会创建文件、替你选择目录或弹出另存为窗口。首次手动保存成功后，后续编辑便可自动保存。

结构编辑草稿必须先成功同步到文档源码。输入法组合输入、校验失败或同步冲突会阻止该文档自动保存，界面保留未保存/待同步状态。自动保存不会关闭公式编辑窗口或抢走输入焦点。

## 查看状态与处理失败

状态显示在各文档标题下方，副文档的状态也位于编辑器上方，可区分关闭、等待首次手动保存、等待有效草稿同步、等待保存、保存中、已保存和保存失败。成功采用非阻塞状态反馈；仍有更新修改时，文档未保存标记继续保留。

遇到外部修改、文件被删除、只读、权限不足、路径不可用或编码失败时，保留内存内容，并在对应文档显示原因及“重试保存”。该文档的自动保存暂停，继续输入不会无限重试，也不会阻止另一文档正常保存。修复原因后点击“重试保存”或按 `Ctrl+S`；成功后恢复正常调度。

若检测到外部版本变化，普通重试仍会保护外部版本。可以使用“另存为”保存当前内存内容到自己选择的新文件，再决定如何处理原文件。应用不会静默覆盖外部版本、自动更换编码或替换无法编码的字符。

## 切换、另存为与退出

手动保存也在后台执行。保存期间可以继续编辑；一次旧内容的保存完成，只确认那次实际写入的内容，后续输入不会被旧结果覆盖。另存为和重命名会先协调正在进行的保存；提交正在完成时，请等待结果后再操作。

开启自动保存不会跳过未保存保护。切换文件、关闭主/副文档或退出时，只要仍有未保存内容、待同步草稿或尚未确认的保存结果，仍需按提示处理。正在完成的提交不能被“放弃”追溯撤销，界面会说明已写入磁盘的实际状态。

**确认“放弃”会立即恢复该文档最后保存的内容。** 随后即使取消打开对话框，或目标文件打开失败，已放弃的内容也不会被延迟自动写回。

跨文件替换、快照回滚等磁盘事务开始前会协调保存，并在事务结束后重新检查当前文档和基线。导出、阅读位置与撤销历史继续使用现有流程；阅读状态仍不保存未保存的稿件正文。

## 维护与验证

`src/autosave.rs` 负责两份文档的防抖、身份校验、结果接收与失败暂停；`Document::save_guarded` 复用编码、路径限制、同目录临时文件和原子替换核心。结果只更新实际已提交的保存基线，不替换当前编辑缓冲区。取消通过提交闸门确认；被取消但尚未结束的任务仍被计入，防止切换文件或反复开关积累后台线程，每个文档窗格至多一个实际保存任务，手动请求以单个待处理项保留。

保存与批量替换/回滚使用进程内锁；Windows 同一会话中的 MDcard 进程还共用系统命名互斥量，Linux 同一用户使用文件锁。外部编辑器不参与此锁，仍通过提交前的磁盘字节基线复核发现冲突；这不提供其他程序的版本历史或任意外部写入者之间的事务保证。

2026-10-26 当前行为与本次证据见[稿件恢复验收](CRASH_RECOVERY_ACCEPTANCE_2026-10-26.md)。[2026-10-25 默认开启记录](AUTOSAVE_DEFAULT_ON_2026-10-25.md)与[初版验收](AUTOSAVE_ACCEPTANCE_2026-10-25.md)均为历史，不能代替当前默认策略和验证。可复跑 `python scripts/check.py --desktop --acceptance`；Windows GUI 使用 `pwsh -STA -File scripts/verify-autosave-windows.ps1 -Exe <本次候选exe>`，需要已解锁桌面，操作期间请勿同时编辑真实稿件。
