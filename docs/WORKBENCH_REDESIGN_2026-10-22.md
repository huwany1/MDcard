# MDcard 工作台重设计（2026-10-22）

## 冻结目标与边界

基线源码 `99465ba`，基线 Windows 程序为 `dist/windows/MDcard.exe`，SHA256 `c9c6981712f054578587d4a1fe978330eaec0920b5372eee6e4032a85473af3a`。本轮分支 `codex/workbench-redesign-2026-10-22`。既有 Linux 分发程序版本不同，不作为本轮实现或兼容性证据。1 个实现子代理、主代理独立验收；不增加多标签、停靠框架或迁移 Rust/egui。

真实基线截图：`evidence/workbench-redesign-2026-10-22/before/zh-CN-Light/`。界面问题：侧栏检索按钮与顶部重复、绝对路径只露前缀、文件树/目录/最近文档连续堆叠且独立小滚动区浪费高度、缺少文档身份与活动窗格层级、工具栏常规按钮同等突出、渲染器技术信息与写作信息同层。主代理已独立查看同条件截图。

## 区域职责与布局

```text
┌ 交通灯 / 侧栏开关 ───── 当前工作区 ───────── MDcard ┐
├ 新建 打开 保存 | 文件菜单 | 搜索文件 ─── 编辑/分屏/阅读 ┤
├ 工作区名 + 文件夹/刷新 ┬ 文档名 / 相对路径 / 活动状态 ┬ 副文档 ┤
│ 文件 / 大纲 / 最近     │ 源码及局部操作 | 预览          │ 同层文档头 │
│ 当前导航完整可用高度   │ 可滚动文稿内容                │ 编辑区     │
├ 操作反馈 ─────────────── 文档统计 / 编码 ────────────┤
```

- 标题栏负责窗口与工作区身份；文档名移至正文顶部文档头，完整路径可悬停查看。
- 工具栏保留高频文件动作；文件菜单收纳另存为、编码及导出，搜索菜单集中Quick/当前查找/全局搜索，更多菜单收纳结构编辑与设置。宽窗快速文件搜索另有明确按钮，快捷键保留。
- 侧栏将文件、大纲、最近文档改为互斥导航视图。工作区名优先显示末级目录，完整根路径悬停可见；文件树使用剩余高度。
- 新增“打开文件夹”仅改变浏览工作区，不替换当前文档、撤销链或未保存稿件；在后台事务忙时禁用。搜索工作区随明确文件夹选择更新，普通文档切换继续保留既有根目录规则。
- 主副文档使用共享文档头：文档名、路径提示、未保存文字/圆点、当前活动窗格标记。焦点由真实编辑器状态驱动。
- 状态栏显示真实操作反馈与文档统计；渲染器信息留在偏好设置和统计悬停说明中。

## 组件规范

颜色采用中性 Mac 风格纸白/石墨；正文、辅助文本、分隔、选择和焦点使用共享语义色。间距 4/8/12/16/24，工具栏高 44、标题栏 40、文档头 36、常规控件32、文件行28。UI 13、辅助12；正文保留字号设置与源码坐标。线性图标14–17、线宽1.4；圆角控件6–7、分组8、窗口14。强调色只表达当前选择和焦点，活动窗格兼有文字标记；dirty兼有符号和文字。

菜单、搜索、结构、编码、导出、设置使用共享原生按钮/窗口样式。错误、未保存提示、加载与空视图必须保持可操作；继续采用既有模态/非模态焦点返回规则。

设计依据：[Apple Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)、[Apple Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars)、[JetBrains UI overview](https://plugins.jetbrains.com/docs/intellij/ui-overview.html)。本项目设计取舍为工程判断，不宣称平台认证。

## 性能契约（实现前冻结）

同机 Windows、OpenGL、reduce motion、15px、3000标题/12000行夹具，禁止测量时并行编译；55个原生SendInput单键注入→GPU完成。原始基线在 `reports/performance-before/result.json`：输入P95 **8.8643ms**/max10.0483；滚动P95 **8.2525ms**/max32.3192，1094帧中3帧超16.667ms，既有严格全帧门槛失败并保留。

本轮相对P95容差 `baseline + max(2ms, baseline×20%)`：输入≤10.8643ms、滚动≤10.2525ms；首次GPU完成允许增加20ms。保留既有输入16ms、滚动16.667ms严格子项结果，失败不能用P95通过替代。切换/搜索使用同一观测边界、200ms可见响应目标，脚本等待不计作纯程序耗时。模式/缩放/主题基线P95分别139.4235/26.3577/110.2671ms，相对容差max(10ms,20%)，并保留200ms观测目标。搜索baseline实测1600文档/100轮（148.62s）：可见P95 12.008ms/max13.2039ms，worker max6.4063ms；基线证据 reports/search-before/performance.json。搜索采用1600文档、100轮、相同原生输入及report观测，P95容差baseline+max(5ms,20%)；另保留P95<50ms/worker max<50ms既有门槛。短程内存观测不代表长期泄漏保证。

## 最终入口清单与操作步骤比较

| 区域 | 入口与职责 |
|---|---|
| 标题栏 | 交通灯、拖动/最大化、侧栏开关、当前工作区名 |
| 文件工具 | 宽窗新建/打开/保存图标；窄窗保留保存，其他动作收进文件菜单 |
| 文件菜单 | 新建、打开、保存、打开文件夹、导出、另存为、欢迎文档、编码与指定编码打开 |
| 搜索菜单 | 快速文件搜索、当前文档查找替换、工作区全文搜索 |
| 更多菜单 | 结构编辑、偏好设置 |
| 快速搜索按钮 | 宽窗放大镜/柔和边框/快捷键提示；触发Quick Switcher，不伪装成可输入文本框 |
| 文件/大纲/最近 | 工作区文件树、当前文档标题、会话最近文件；各自使用侧栏剩余高度 |
| 文档头与正文局部操作 | 文档身份、完整路径提示、活动与dirty状态；源码结构/换行及预览标题同层 |
| 状态栏 | 实际操作反馈、文档统计、编码切换；渲染器留在设置及悬停说明 |

步骤以“点击命令入口”为一次，系统选择器内路径选择单独记录，键盘快捷键保持原契约。文件夹：原先无明确入口，需先打开目标文件才能间接换根；现在侧栏文件夹按钮1次→系统选择文件夹，当前dirty稿件保留。快速打开：宽窗原侧栏1次→新工具栏1次；窄窗从搜索菜单2次，Ctrl+P仍1次。全局检索：原侧栏/工具栏各1次的重复入口→搜索菜单2次，Ctrl+Shift+F仍1次；用一次额外菜单点击换取侧栏正文空间。大纲：原混排且高度18%→大纲tab1次后完整空间；退出时切文件tab1次。保存、三模式、编码、设置、导出快捷键保持；弹窗退出恢复原位置。

## 视觉与交互修订记录

- R1：主代理认可文件/大纲/最近分区和冗余清理，指出add_sized的父布局使名称仍居中；改为独立left_to_right子布局，实际截图再次复核。
- R1：全局Heading缩小连带影响Markdown H1；恢复文稿Heading27，仅在设置/编码/保护弹窗使用局部20px标题。
- R1：Quick文字按钮缺少搜索可供性；改为原生按钮响应与键盘语义、向量放大镜、柔和底/边框、快捷键。
- R1主代理原生点击发现Context嵌套锁导致无响应，原稿字节安全。修复为input闭包只读取pointer，离开闭包才查询layer；增加真实PointerButton绘制回归。
- R4：主代理独立文档闭环及双窗焦点通过；主预览点击增加对旧副编辑焦点的释放，避免下一帧重新抢回活动状态。
- R4：File菜单职责过宽，拆分文件/搜索/更多菜单；小窗口收纳新建/打开图标及Quick按钮，保留菜单和快捷键可达性。
- 大纲专属视图使用28px虚拟行和24px控件，修复原22px虚拟行与32px按钮不一致的风险；小文档标题由Markdown解析器的全局字节坐标定位，重复标题按序号区分。
- R6原生文件夹Cancel精确选区仍在但焦点丢失；R7在系统picker返回后延迟恢复原主/副编辑器焦点。原生picker以PID、`#32770`和标题核验，再通过可见系统按钮提交；Alt+S旧驱动输入路由失败保留。
- R7主代理完整导航发现副窗每帧增宽8px并最终挤没主稿。定向真实egui回归先失败（第6帧488→496），修复操作行尾部占位越界，改为行首定高、统一右向操作布局；六语言、超长dirty名称各100帧稳定性回归通过。

历史失败、脚本输入/剪贴板异常与中间截图保留在本轮目录。修订后的最终源码及同包证据以最终验收文档为准。
