## 布局与适配

1. 主工作区：40px工作区标题层，48px操作层，244px导航列，剩余空间为内容。工具层将文件快捷操作、平面菜单、快速查找、三模式分别组织；主操作步骤不增加。
2. 文档身份：52px的文件名/路径两级行，右侧原有活动/修改状态；用短竖标记标识活动编辑窗，中性横线结束身份区域。长路径与名称单行省略并保留完整悬停提示。
3. 保护状态：将原有自动保存与独立恢复文字放在一行，使用11px辅助文字和18px最小交互高；错误/重试控件仍可自然换行，不隐藏恢复入口。绝不将“恢复更新”显示成“文件保存”。
4. 编辑/预览：共享32px分区工具行，分屏为等宽双栏，间隔32px和一条中性细线；阅读沿用现有最大920px宽度规则。正文依旧是视觉中心。
5. 导航：统一三等分导航，工具靠右，计数与列表之间有8px间距；虚拟行实际28px，选中/展开/键盘状态均保持。窄于850px仍按既有规则收起侧栏，分屏仍由原有可用空间检查决定。
6. 设置：宽度520px以内，长说明自然换行；开关在右侧对齐，滚动体限定于窗口可用高度，底部完成按钮固定。窄窗仍呈现全部选项，通过滚动访问，无新增设置页或持久化选项。
7. 导出/查找/结构/恢复：统一16px标题、18px内边距、中性标题栏/边界；导出源身份、格式、页面选项、高级配置及任务操作有明确分区；保留现有底部进度/取消入口。搜索与替换语义、结构编辑命令、恢复行为均不改。
8. 模态：宽度受当前内容区约束，说明与输入分组，底部操作区清楚；设置与编码采用滚动体、固定按钮。缩窄窗口后须重新约束位置，防止阶段一实际越界。

### 设计修订 1.1（先于编辑阅读区实施）

基础样式真实截图显示，HTML初稿使用的等宽源码1.42行距比原生编辑器现有行距松。为保留编辑几何、用户选择/撤销与阅读位置行为，静态图源码行距调整为1.15，接近原生已有排版；不改 `source_layout.rs` 或源码编辑器实现。原22图/HTML/manifest已归档到 `evidence/ui-ux/2026-10-28/design-v1/`，设计关口原哈希仍可复核。此修订只改变静态绘图，不是用最终截图反向冒充先前设计。

### 设计修订 1.2（设置实机适配）

关闭态开关增加辅助文字色的细描边，保持灰色轨道、白色滑块与正常可用标签，避免与禁用混淆；已先更新静态图。egui Modal 会记忆上次Area尺寸：窗口缩小时需要只在尺寸变化帧重测Area，内容区由限定高度的ScrollArea收缩；遮罩继续覆盖整个窗口，安全边距属于弹窗本体，不能用于裁剪遮罩。此适配不清除文档/设置/焦点状态，不更换业务调用。

### 设计修订 1.3（原生浮窗）

浮窗保留egui原生居中标题和现有折叠/关闭入口；先在静态图补齐，避免重写窗口交互。Window水平边距18px、垂直10px，降低标题区过高的比例；模态边距仍18px。恢复窗口的恢复、删除分支与诊断时机相互交织，设计保留原纵向动作顺序，只明确恢复按钮权重、快照预览区域和右侧稍后处理，业务实现不搬移。导出按钮右对齐，进度/取消仍沿用现有分支。

Windows启动器的隐藏标记会被原生框架后续显示覆盖，因此测试实例需要在创建Viewport之前设置初始屏幕位置并禁用初始激活。增加仅由测试启动器传入的 `MDCARD_WINDOW_POSITION`（逻辑坐标x/y）；存在合法坐标时设置 `with_position` 和 `with_active(false)`，未传入时日用启动行为不变。此项属于本任务屏幕隔离的纯窗口展示配置，不写持久化设置、不模拟设备输入。

### 设计修订 1.4（结构工具完整性）

先补齐14图中真实列/行索引控件、Ctrl+Alt+Enter/Backspace增删行、左右键增删列、1/2/3对齐、Alt方向键块移动及实际单元格导航提示，再仅将结构工具五处small_button替换为统一tool_button。每个clicked条件、Command、表格网格和执行流程保持原样。修后针对性重采结构界面并运行现有结构UI/表格测试；其它最终图沿用已验证的相同展示实现。
